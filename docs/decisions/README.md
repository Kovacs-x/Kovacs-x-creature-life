# Architecture Decision Records

Major architecture decisions will be recorded here as Architecture Decision
Records (ADRs) once they have been approved.

ADRs are required for decisions that materially alter simulation boundaries,
the persistence model, brain architecture, rendering technology, networking,
or simulation semantics. Each record should include:

- status;
- context and problem;
- options considered;
- decision;
- trade-offs;
- migration and backwards-compatibility impact;
- testing implications.

Do not record an ADR as approved before the decision has been presented for
review and approval.
